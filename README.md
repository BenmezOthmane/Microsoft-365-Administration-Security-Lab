# Microsoft 365 Administration & Security Lab

## Overview
This project simulates a real-world Microsoft 365 enterprise environment focused on identity management, administration, and security.

It demonstrates practical skills in managing users, groups, access control, and security policies using Microsoft Entra ID and related Microsoft 365 services.

---

## Objectives
- Build and manage a cloud-based enterprise identity system
- Implement security policies and access control
- Automate administrative tasks using PowerShell
- Simulate real enterprise communication and collaboration tools

---

## Technologies Used
- Microsoft Entra ID (Azure AD)
- Exchange Online
- Microsoft Teams
- SharePoint Online
- PowerShell

---

## Key Features
- User and group management (20+ users simulated)
- Role-based access control (RBAC)
- Multi-Factor Authentication (MFA)
- Conditional Access policies
- Exchange Online mailbox configuration
- Teams workspace setup
- PowerShell automation for user and license management

---

## Automation Scripts
- Bulk user creation
- License assignment
- Administrative reporting

---

## Security Focus
- MFA enforcement
- Conditional Access rules
- Secure identity management practices

---

## Notes
This is a lab environment created for learning and demonstration purposes only.
